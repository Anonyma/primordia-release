# Frontend design rules

- Preserve Primordia’s established visual language: white surfaces, Karla body copy, Jost section headings, and existing biological artwork.
- Impeccable leads visual direction; UI/UX Pro Max supports usability, accessibility, and responsive review. Do not independently redesign the same interface with both.
- User-facing readable text must never be smaller than 14px. This is a floor, not a body-text target: use 20–22px for handbook reading text and review its rendered size on mobile and desktop.
- Avoid eyebrow headers, double-slash labels, decorative letter codes, and repeated numbering. Numbers should communicate a useful sequence, not decorate sections.
- For reading pages, use a clear linear flow, useful headings, and comfortable line lengths. Consolidate repeated information instead of scattering it across card grids.
- Accessibility, semantic correctness, usability, and functional correctness override aesthetic preferences.
